# music-vibe-sorter

Project Goal- I am going to build a Java program that allows you to assign every song in a master playlist a specfic vibe and then lets you sort the master playlist into a smaller amount to look through by genre/vibe based on the qualities you want in your new playlist. 

MVP SCOPE
- Set up the repository and basic project structure
- create a song class with title artist and vibe etc.
- write file reading system that pulls from the text file
- create the menu loop
- add the ability to mark a song with a vibe to the objects
- create the filteing logic and the file export to save the new lists.

Tech Stack
- Java
- Javas built in libraries like scanner and io for reading and writing files
- Text file
- No external source

Future Plans
- Automatically get a users playlist/liked songs list from spotify instead of a manual file export
- Suggested vibe detection based on the artist/tempo
- Plain text terminal menu to something that looks nicer
